Arquivo do Crime Publicador

Ferramenta interna do canal de YouTube Arquivo do Crime (documentários de crimes reais do Brasil), usada somente pelo dono do canal.

Como funciona: o servidor do dono produz cada vídeo e manda uma prévia para ele num chat privado. Só depois que o dono aprova aquele vídeo, a ferramenta envia o vídeo e a capa para o próprio canal pelos Serviços de API do YouTube. Todo envio é marcado como conteúdo alterado/sintético (narração por IA) e "não é para crianças".

Não há outros usuários, a ferramenta não acessa canais de terceiros e não mostra dados do YouTube a ninguém.

Desenvolvido com os Serviços de API do YouTube
